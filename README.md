## Task 10 - Google AI Studio

Prompt: `Introduce yourself briefly.`

Response: "Hello! I am Gemini 4 Hydrogen, a large language model built by Google. I'm designed to help you with a wide variety of tasks, including answering questions, writing, coding, brainstorming, and much more. How can I assist you today?"

Interpretation: the answer was short and general, as the prompt asked. AI Studio also showed the token count (94 tokens) and the settings panel, so I could see that the answer depends on the selected model and parameters, and that the output should be double-checked, because the model can make mistakes.

## Task 16 - How the tools work together

In a real project these tools form one workflow. HTML is the product itself: the code that the browser reads and renders as a web page. VS Code is the workplace where developers write and edit that code, and its Source Control panel gives a visual interface to Git. Git runs locally and records every change as a commit, so the history is traceable and any earlier version can be restored. GitHub stores the same repository online: it is the shared copy the team pushes to and pulls from, where collaborators are invited and code is reviewed. Google AI Studio supports the work with AI: developers use it to generate or explain code, draft content and test prompts before building AI features into the product.

In short: write in VS Code, track with Git, share on GitHub, speed up with AI Studio, and the result is the HTML page users see.
